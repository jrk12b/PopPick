# PopPick

[![PopPick](https://github.com/jrk12b/PopPick/actions/workflows/node.js.yml/badge.svg)](https://github.com/jrk12b/PopPick/actions/workflows/node.js.yml)

PopPick is a React Native mobile app that lets you discover books, movies, and video games, and organize them into personalized lists: To Watch/Play/Read, Watched/Played/Read, and Liked. Search, save, and enjoy your favorites anytime, all in one convenient place!

# Running Locally
- `npm i`
- `npm start`

# install pods
- `cd ios`
- `pod install`

# run using expo
- `npx expo run:ios`
