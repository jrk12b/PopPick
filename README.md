# PopPick

[![PopPick](https://github.com/jrk12b/PopPick/actions/workflows/node.js.yml/badge.svg)](https://github.com/jrk12b/PopPick/actions/workflows/node.js.yml)

PopPick lets you discover books, movies, and video games, and organize them into lists: To Watch/Play/Read, Watched/Played/Read, and Liked. Search, save, and enjoy your favorites anytime!

# Running Locally
- `npm i`
- `npm start`
